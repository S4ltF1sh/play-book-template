# Tóm tắt chương demo

- Playbook = **chương → sections**; ba loại section: đọc, quiz xen kẽ, bài tập — mỗi loại một cơ chế mở khóa riêng.
- Bài tập chấm tự động bằng **checks**: regex trên output của từng pane; tất cả pass ⇒ section done.
- Playground chạy code **thật** trên máy bạn qua pty, mỗi pane một process độc lập; hỗ trợ nhiều toolchain (`c`, `cpp`, `python`, `node`, `kotlin`, `java`).
- Đáp án mẫu luôn có sẵn sau disclosure "📖 Đáp án mẫu", kèm nút chép vào editor và nút hoàn thành dự phòng.
- Cuối chương: tóm tắt + bảng thuật ngữ + trắc nghiệm tổng kết (chính là trang bạn đang đọc và trang kế tiếp).
